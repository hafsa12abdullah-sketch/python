## 9. If / Elif / Else

```python
marks = int(input("Marks: "))

if marks >= 80:
    print("A Grade")
elif marks >= 60:
    print("B Grade")
elif marks >= 40:
    print("C Grade")
else:
    print("Fail")
```

## 23. Exception Handling

```python

    number = int(input("Number: "))
    print(number)

```

## 24. File mein write karna

```python
file = open("test.txt", "w")

file.write("Hello Python")

file.close()
```

Better method:

```python
with open("test.txt", "w") as file:
    file.write("Hello Python")
```

## 25. File read karna

```python
with open("test.txt", "r") as file:
    data = file.read()

print(data)
```

# 🔥 Sabse important practice programs

In basic concepts ke baad ye programs khud banana:

### Program 1 — Even/Odd

```python
number = int(input("Number enter karo: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")
```

### Program 2 — Calculator

```python
a = float(input("First number: "))
operator = input("Operator (+, -, *, /): ")
b = float(input("Second number: "))

if operator == "+":
    print(a + b)

elif operator == "-":
    print(a - b)

elif operator == "*":
    print(a * b)

elif operator == "/":
    print(a / b)

else:
    print("Invalid operator")
```

### Program 3 — Multiplication Table

```python
number = int(input("Number: "))

for i in range(1, 11):
    print(number, "x", i, "=", number * i)
```

### Program 4 — Sum 1 to 100

```python
total = 0

for i in range(1, 101):
    total += i

print(total)
```

### Program 5 — Password Check

```python
password = input("Password: ")

if password == "12345":
    print("Login successful")
else:
    print("Wrong password")
```

### Program 6 — Simple Number Guessing Game

```python
import random

secret = random.randint(1, 10)

guess = int(input("1 se 10 ke darmiyan number guess karo: "))

if guess == secret:
    print("Correct!")
else:
    print("Wrong! Number was:", secret)
```

### Python seekhne ka order

**Print → Variables → Data Types → Input → Operators → If/Else → Strings → Lists → Tuples → Sets → Dictionaries → For Loop → While Loop → Functions → Exceptions → Files → Modules → OOP**

Agar aap **zero se Python seekh rahe ho**, to pehle upar ke **1–10 topics** achhi tarah practice karo; phir loops aur functions par jao.
